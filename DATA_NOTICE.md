# Dataset provenance

MIT-BIH Arrhythmia Database, version 1.0.0.
Source: https://physionet.org/content/mitdb/1.0.0/
DOI: https://doi.org/10.13026/C2F305

The starter includes the unmodified `.hea`, `.dat`, and `.atr` files for every
record listed in the source `RECORDS` file. Optional annotation sets, viewer
files, and other ancillary files are not included. The file manifest records
URLs, sizes, retrieval time, and SHA-256 values; it does not define a data split.
